#   凸包算法的理论与实现

凸包是计算机图形学和计算几何领域一个非常重要的基础概念，应用广泛。例如，三维凸包对游戏碰撞检测速度的提升。由于三维凸包比较复杂，本文将介绍二维凸包中一个比较常见的算法。二维凸包的定义是，给定一些离散的点集，求出包含这些点的最小面积的凸多边形。感性理解上可以这样想象，桌子上有一堆钉子，用一个具有很好弹性的橡皮筋，先将橡皮筋无限拉伸并包围住所有的钉子，然后放开橡皮筋，这个时候橡皮筋包围在最外面一圈的钉子上。此时，橡皮筋围成的多边形就是凸包。

## 一、Graham-Scan算法概述
凸包实现的算法有多种，例如极点法、极边法、卷包裹法、增量法以及分治法等。本文从算法的复杂度和可理解性上介绍一种较为折中的算法-Graham-Scan算法。该算法的基本步骤如下：

1、选出x坐标最小的点作为极点（x坐标相同时，选y最小的点），这个点必在凸包上。<br>
2、将其余的点按照相对于第一步选出来的极点进行极角排序，极角相同的情况下，比较 
与极点的距离，距离近的优先。 <br>
3、用一个栈S存储凸包上的点，先将第一步选出来的极点入栈，再将第二步选出来的极角  
最小的点入栈。用另外一个栈T存储剩下的其它点。将第二步中其余的n-2个点按照反序入栈T。<br>  
4、循环栈T，检查S栈的次栈顶、栈顶以及T栈的栈顶这三个点组成的折线段的拐向，判断
是否向右拐（即叉积 小于等于0）<br>
5、如果是，S出栈，返回4继续检查直到S栈中只剩两个元素或者向左拐，此时，将T栈的栈顶点出栈，再入S栈。<br>
6、直到T栈为空，此时算法结束，S栈中的顶点序列即为凸包。

## 三、C++算法实现

对于本人来说，比较熟悉c++语言，所以就用C++代码片段展示算法实现。
```cpp
void convexhull2DGrahams(std::vector<Point2d>& _points, std::vector<Point2d>& _convex)
{
        if (_points.size() <= 3)
                return;

        int index = 0;

        //选择出一个极点，x轴坐标最小的点，x坐标相同，选y最小的点
        for(int i = 1; i < _points.size(); i++) 
        {
                if ( _points[i][X] < _points[index][X]
                        || ((_points[i][X] == _points[index][X]) 
                        && (_points[i][Y] < _points[index][Y])) ) 
                {
                        index = i;
                }
        }
    
        std::swap(_points[0], _points[index]);
        //其余的点按照到极点的角度大小排序，相同的情况下，距离近的优先
        std::sort(std::next(_points.begin()), _points.end(), [&](const Point2d& a, const Point2d& b)
        {
                if (left(_points[0], a, b) || (pallel(_points[0], a, b) &&
                                        jmk::distance(_points[0], a) < jmk::distance(_points[0], b)))
                {
                        return true;
                }
                return false;
        });
        
        //将排序好的点前两个点放入栈中
        std::stack<Point2d> resultStack;
        resultStack.push(_points[0]);
        resultStack.push(_points[1]);
        
        //将其余的点按照相反的顺序放入另外一个栈中
        std::stack<Point2d> tempStack;
        for (int i = _points.size() - 1; i >= 2; i --)
        {
                tempStack.push(_points[i]);
        }
        
        //按照顺序扫描其它点
        while (!tempStack.empty())
        {
                Point2d &top = resultStack.top();
                resultStack.pop();
                Point2d &secondTop = resultStack.top();
                resultStack.push(top);
                if (!right(secondTop, top, tempStack.top()))
                {
                        resultStack.push(tempStack.top());
                        tempStack.pop();
                }
                else
                {
                        //只有当结果的S栈中的元素个数大于2时才出栈
                        if (resultStack.size() > 2)
                        {
                                resultStack.pop();
                        }
                }
        }
        
        while (!resultStack.empty())
        {
                _convex.push_back(resultStack.top());
                resultStack.pop();
        }
        
        //将顶点逆序变为逆时针
        std::reverse(_convex.begin(), _convex.end());
}
```

关于代码中的几点说明：
1、Point2d是自己定义的数据结构，这个很容易理解
2、left和right是分别传递三个参数a,b,c，代表三个点，表示c是否在ab线段的左侧或者右侧，这个也比较简单，用二维向量的叉乘就可以判断。
3、tempStack这个栈可以用数组或者其它效率更高的方式实现，毕竟如果原始顶点的数据
比较大的话，多了一次拷贝数据的开销，只不过用栈来实现非常简单。
4、**将顶点逆序变为逆时针**这个步骤是可选的，取决于你的应用。
5、**其余的点按照到极点的角度大小排序**这个步骤中并没有实际计算极角的大小，而
是比较两个点和极点之间的走向，例如一个点在极点和另外一个点之间连线的左侧，说明
这个点的极角比另外一个点的极角大。
