## 一、程序1 多线程并行
cs149作业1的程序1

初始版本的实现思想是每一个线程运行连续的若干行，代码如下：
```cpp
    //确定当前线程的起始行和行数
    uint32_t rowsPerBlock = args->height / args->numThreads;
    if (args->height % args->numThreads)
    {
        rowsPerBlock += 1;
    }

    uint32_t startRow = rowsPerBlock * args->threadId;
    rowsPerBlock = std::min(args->height - startRow, rowsPerBlock);
```

从4-12线程都没有达到理想的加速比，主要是每个线程的负载不均衡导致。

怎么样实现均衡分配？一个简单的思路是线程i计算所有的k * numThread + i行，需要在mandelbrotSerial.cpp另外实现一个函数如下：
```cpp
void mandelbrotStepSerial(
        float x0, float y0, float x1, float y1,
        int width, int height,
        int startRow, int step,
        int maxIterations,
        int output[])
{
    float dx = (x1 - x0) / width;
    float dy = (y1 - y0) / height;

    for (int j = startRow; j < height; j+=step)
    {
        for (int i = 0; i < width; ++i)
        {
            float x = x0 + i * dx;
            float y = y0 + j * dy;

            int index = (j * width + i);
            output[index] = mandel(x, y, maxIterations);
        }
    }
}
```

上述的函数的意思是每一个线程进行迭代，以3个线程为例，第一个线程计算第0，3，6，9...等行。然后线程的入口函数的函数调用需要改为
```cpp
mandelbrotStepSerial(args->x0, args->y0, args->x1, args->y1, args->width, args->height,
                         args->threadId, args->numThreads, args->maxIterations, args->output);
```
经过这样，加速比上升就比较明显了。经过任务分配优化后的加速比如下：

3线程 (2.95x speedup from 3 threads)
4线程 (3.90x speedup from 4 threads)
5线程 (4.49x speedup from 5 threads)
6线程 (5.30x speedup from 6 threads)
7线程 (6.25x speedup from 7 threads)
8线程 (6.80x speedup from 8 threads)
9线程 (7.48x speedup from 9 threads)

可以看到，随着线程数量的增多，加速比并不是线性增长，主要的原因是每个线程的负载会更加不均衡。
