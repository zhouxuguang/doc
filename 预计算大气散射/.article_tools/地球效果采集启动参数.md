# 地球效果采集启动参数（写作工作记录）

地球启动参数采用现有 `GNX_MAP_*` 接口，例如轨道取景为：

```sh
env GNX_MAP_ATMOSPHERE=1 GNX_MAP_ATMOSPHERE_ALGORITHM=legacy \
  GNX_MAP_PANEL=0 GNX_MAP_TARGET_LON=110 GNX_MAP_TARGET_LAT=23 \
  GNX_MAP_EYE_DISTANCE=1000000 GNX_MAP_PITCH=65 \
  GNX_MAP_SCREENSHOT="$PWD/atmosphere_scattering_images/earth_orbit.png" \
  GNX_MAP_SCREENSHOT_FRAMES=180 MTL_DEBUG_LAYER=0 \
  /Users/zhouxuguang/work/mycode/GNXMapEngine/build-map-native/GNXMapEngine.app/Contents/MacOS/GNXMapEngine
```

此命令需要已经存在的本地 native 构建和瓦片数据。`GNX_MAP_EYE_DISTANCE` 是目标距离，不是视点高度；`GNX_MAP_PITCH` 的 0 度取全球正视、较大值取近地水平观察，也不是 demo 中的太阳天顶角。
