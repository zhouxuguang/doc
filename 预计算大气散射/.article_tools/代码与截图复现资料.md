文章工作目录中保留以下辅助资料。它们是写作、绘图和验证工具，不是对引擎源代码的补丁。

| 文件 | 用途 |
|---|---|
| `.article_tools/make_figures.py` | 用公式生成 16 幅 SVG 与 PNG 技术图 |
| `.article_tools/make_reference_figures.py` / `figure_style.py` | 按参考页面四幅几何图重绘补图 A—D，共享图形样式与排版检查 |
| `.article_tools/qa/reference_geometry_validation.json` | 补图的球面交点、相切关系和角度更新数值核验 |
| `.article_tools/make_paper_reading_figures.py` | 根据原论文 Figure 2、Figure 1 的概念绘制中文补图 E、F |
| `.article_tools/make_explanatory_figures.py` | 绘制正文补图 G—J：纹素中心、角积分、纹理生命周期、椭球代理 |
| `.article_tools/qa/explanatory_figure_validation.json` | 新补图的纹理坐标、角权重与代理几何数值检查 |
| `.article_tools/verify_explanatory_examples.py` / `qa/main_text_examples_validation.json` | 正文算例复核：传输方程极限、纹素权重、地平线端点、四维插值、调度与椭球高度 |
| `.article_tools/validate_article.py` | 汇总公式编号、相对路径、重复段落、26 幅示意图排版及源码和截图摘要检查 |
| `.article_tools/qa/paper_reading_examples_validation.json` | 单次样本贡献、有限段减法和 100 km 参数化例子的复算结果 |
| `.article_tools/verify_math.py` | 相函数、LUT、透射率和有限散射数值核验 |
| `.article_tools/build_capture.py` | 构建复制入口的独立 demo 采集程序 |
| `.article_tools/capture_engine.py` | 按固定参数采集两类引擎视图并记录日志 |
| `.article_tools/qa/*.log` | 本次采集的实际运行日志 |
| `.article_tools/render_article.py` / `render_math.js` | 提取并用 KaTeX 解析 LaTeX，生成本地校稿预览 |
| `.article_tools/reference/functions.glsl` / `model.cc` | 写作时下载的官方参考源码快照 |
| `.article_tools/reference/LICENSE` | 参考源码 BSD-3-Clause 许可证原文 |
